# linux-notes

A running log of distros I've used, problems I've solved, and things worth remembering.
Meant to be a living document - add a note every time something takes more than 10 minutes to figure out.

| Directory | Topic |
|---|---|
| `arch/` | Arch Linux on archbox - k3s worker, homelab server (i3-4130T) |
| `debian/` | Debian 13 - mikepc (RTX 5060 Ti), debianbox, debianbook (Chromebook); MikeInspiron (historical) |
| `nixos/` | NixOS era notes - migrated to Debian 13 May 2026 |
| `fedora/` | Fedora notes |
