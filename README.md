# linux-notes

A running log of distros I've used, problems I've solved, and things worth remembering.
Meant to be a living document - add a note every time something takes more than 10 minutes to figure out.

## Structure

| Directory | Topic |
|---|---|
| `arch/` | Arch Linux on archbox - k3s worker, homelab server (i3-4130T) |
| `debian/` | Debian 13 - mikepc (RTX 5060 Ti), MikeInspiron, debianbook (Chromebook) |
| `nixos/` | NixOS era notes - migrated to Debian 13 May 2026 |
| `fedora/` | Fedora notes |
| `hardware/` | Hardware-specific - RTX 5060 Ti Blackwell, Samsung Chromebook Pro |

## Distro History


## How to Use

Each note is a standalone markdown file. No clever tooling - just files.
Add a new `.md` when you solve something that cost you time.
